# CarbonJ SVG HTML visual systems

These are reusable directions, not rigid content templates. Keep the default Noto Sans SC typography in every system. The user may select one system, combine one palette with another layout, or name a new direction. Ask before each content-making invocation after the user chooses long HTML or PPT-style slides.

## 1. Green · 清爽网格

- Palette: paper `#F1F1EB`, ink `#151515`, signal green `#A8E833`, white `#FFFFFF`, quiet gray `#72766E`.
- Mood: clear, curious, optimistic and technology-aware.
- Layout: strong alignment, visible grid, numbered steps when order matters, compact information cards. Use green only to call attention to the key idea.
- Use for: explainers, tutorials, product walkthroughs, AI concepts.

## 2. Refined Orange · 温润爱马仕橙调

- Palette: warm ivory `#FBF6EF`, deep brown `#352820`, muted orange `#D97843`, warm taupe `#EAD7C6`, white `#FFFFFF`.
- Mood: warm, polished, tactile and confident. Orange is an accent; avoid loud full-bleed saturated orange.
- Layout: generous margins, elegant rules, editorial title blocks and a restrained orange signature. Do not use Hermès logos or imply affiliation.
- Use for: creator stories, practical guides, brand or product narratives.

## 3. Macaron · 多彩马卡龙

- Palette: soft ivory `#FFFDF8`, charcoal `#30313A`, lilac `#C8C1EF`, mint `#BFE0CF`, peach `#F3C0AF`, butter `#F1DFA4`, optional sky `#BFD8ED`.
- Mood: approachable, bright and playful without looking childish.
- Layout: assign pastel colors to distinct content groups; balance color area and whitespace. Use color to encode categories or stages, not as random decoration.
- Use for: beginner explainers, creator workflows, friendly product education.

## 4. Consulting · 高级咨询报告感

- Palette: white `#FFFFFF`, navy `#142D43`, blue `#1D6595`, slate `#65798A`, pale gray-blue `#F2F5F7`, divider `#CBD4DB`.
- Mood: precise, calm, evidence-led and executive-ready.
- Layout: conclusion first; then evidence, comparison, implications and recommended action. Favor compact charts, clear labels, restrained rules and generous alignment.
- Use for: market or industry analysis, research synthesis, strategy and deep-dive teaching.
- Do not copy consulting company logos, proprietary slide layouts or imply endorsement.

## 5. Anthropic-inspired · 温暖理性

- Palette: ink `#141413`, warm white `#FAF9F5`, clay orange `#D97757`, blue `#6A9BCC`, sage `#788C5D`, light gray `#E8E6DC`.
- Mood: thoughtful, human, calm and editorial.
- Layout: restrained warm neutrals, precise hierarchy, limited accent colors, a simple geometric or organic signature element. Use Noto Sans SC as the Chinese typeface unless the user asks otherwise.
- Use as a visual reference only. Do not use Anthropic logos or imply the deck is official or endorsed.


## Chart and composition vocabulary

Give each style a varied but coherent set of components. For a style showcase, include an actual chart, a numerical card and an annotation in each example, using visibly labelled demonstration data. Use the same care for chart typography, spacing, labels and color as for the headline.

- Green uses dense but orderly KPI blocks, bar charts, progress bars and process grids.
- Refined Orange uses editorial proportions, large meaningful numbers, donut charts, fine rules and milestone timelines.
- Macaron uses coordinated pastel metric cards, conversion stages, rounded charts, sparklines and category matrices.
- Consulting uses takeaway headlines, ranked horizontal bars, comparison charts, compact tables and decision frameworks.
- Anthropic-inspired uses restrained annotations, warm area or line charts, dot plots, quiet metrics and generous whitespace.

Choose graphical forms that fit the material. Preserve all marks, labels and values as editable SVG objects. Use supplied data for factual content. When a design example needs invented values, mark them clearly as demonstration data and keep arithmetic consistent.

## Font treatments shown in previews

Keep Noto Sans SC / Source Han Sans as the default across all style systems. Every style preview should visibly show the same Chinese headline and a short body sample so the user can compare hierarchy and weight, not just palette. When the user wants font alternatives, show a separate same-copy specimen: Noto Sans SC as default; Noto Serif SC for editorial headlines paired with Noto Sans SC body; LXGW WenKai for short warm emphasis; Ma Shan Zheng only for a few expressive display characters. Do not apply an alternate font to a finished deck unless the user selects it.

## Cross-style CarbonJ content rhythm

Use a clear hook or conclusion, explain with ordered points or a concrete workflow, include examples or evidence from the user's material, then close with a practical takeaway. Keep Chinese labels and headings concise. Avoid invented facts and statistics.
